# Akram and Ashraf Nigeria Limited — Website

Premium static website for Akram and Ashraf Nigeria Limited.

## Version
Visual redesign with transparent company logo, scroll-reveal animation, interactive cards, image lightbox, responsive navigation, form loading states, and GitHub Pages compatibility.

## Deployment
The site is designed for GitHub Pages. Keep `index.html` at repository root and keep the `assets/` folder intact.

Custom domain: `akramandashraf.com.ng`

The site contains no server-side code. Enquiry forms use FormSubmit and redirect to the site's thank-you page.
